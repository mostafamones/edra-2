# Terms

| Term | Meaning |
|---|---|
| Account | A person's Edra sign-in identity |
| Academy student profile | Their persistent relationship with one academy |
| Annual participation/record | That year's placement, contacts and participation |
| Program | One level, optionally with a track; content is organized within its academic-year scope, which units inherit. This does not prescribe a separate database entity. |
| Schedule / session | Planned teaching / actual teaching meeting |
| Content unit / release | Learning material within a program / its published delivery in that program's year and audience; no separate yearly-release setup step |
| Release / finalize / announce | Make content visible / establish official attendance / establish official results |
| Question Sheet / Answer Sheet / Written Work | Authored questions / externally supplied questions with numbered answer entry / manually reviewed written work |
| Explanation grant / answer grant | Temporary explanation access / assessment-earned solution access |

Question Sheet and Written Work apply to all assessments; Answer Sheet is assignment-only. Internal grading keys are not Answer Sheet parts. Saving is distinct from final submission and official academic actions.
