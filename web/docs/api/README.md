- [Assignments OpenAPI](assignments.openapi.yaml).

Contracts were checked against current route handlers, v1 builders, shared HTTP authority/errors and relevant domain types. This is source verification, not deployment or cloud verification. Bearer authentication is separate from cookie web actions; mixed cookie/bearer requests are rejected. Native clients do not need CORS; browser callers use configured origins.

Sessions v1 includes starting a session from a schedule (`POST /api/v1/academies/{academyId}/sessions`, idempotent by start key) and listing startable schedules (`GET /api/v1/academies/{academyId}/schedules`, offset-paged). Ending, archiving and restoring sessions remain web actions.

Attendance v1 check-ins record Late atomically with the check-in and its receipt for both identifiers (`late_after_minutes`); explicit bulk changes stay capped at 500 rows, all or nothing; `POST /api/v1/sessions/{sessionId}/attendance/unrecorded-absences` marks every remaining expected Unknown student of a mandatory session Absent against a reviewed revision (`409 ATTENDANCE_REVIEW_STALE`); and `GET`/`POST /api/v1/sessions/{sessionId}/attendance/attendees` search for and explicitly append unexpected attendees (`origin: unexpected`). These require migrations `20261019100000` and `20261019100100` on the target database; source support is not deployment.

Assignment source uses active/closed/archived and ready, with no assignment Publish step. Current v1 supports staff reads with server-decided `actions` and `student_codes_enabled`, full-cohort marks search, per-question answers and part marks, code resolution and atomic selected result announcement (`POST /api/v1/assignments/{assignmentId}/results/publications`, `409 PUBLICATION_REJECTED` with per-student failures). Student submissions are not part of this contract. Part kinds retain source identifiers online_questions/answer_sheet/file_upload while product labels are Question Sheet/Answer Sheet/Written Work.

Current role enforcement uses owner/head_admin/admin/instructor; Head Admin has the Owner/Admin authority of these endpoints. Every request requires an active membership: a suspended or removed staff member is denied in that academy (403/404) with an otherwise valid token, and `/api/v1/academies` omits suspended memberships. Task 4 adds stable required-cohort provenance and live optional eligibility; `recipient_count` remains the captured required count, with separate current required and eligible counts. Optional and ended non-submission is excluded from `not_received`. Controlled exclusions/key corrections belong to Task 3. Read [product assessments](../product/domains/assessments.md) for intended behavior and [module integration](../../src/modules/assignments/README.md) for current source limits.

Quizzes v1 is staff reads only (list, detail with key, students with work and result state). Staff quiz commands are cookie web actions. The student quiz database wrappers resolve connected ordinary-session accounts but still deny through `content_unavailable` pending content integration, and have no HTTP route; see [quiz module integration](../../src/modules/quizzes/README.md).

Exams v1 is staff reads only (list, detail with key, students with work, departures and result state). Staff exam commands are cookie web actions. The student exam database wrappers resolve connected ordinary-session accounts; a bounded cookie-only `POST /api/student/exams/{examId}/departure` supports teardown delivery through the same fenced service (see Exams OpenAPI); standalone exams need no released content, and attached exams are denied pending the content integration. The student web app (EDRA-232) uses cookie server functions over `list_my_exams`, `get_my_exam_overview` and `start_my_exam`; there is no student bearer API. Student state returns question material only during the student's active attempt or after solution qualification, and official results are total-only. Source contracts do not prove deployment. File/photo evidence and solution videos are deferred; see [exam module integration](../../src/modules/exams/README.md).
