# Search and commands

Both sidebar Search buttons open the same composed shadcn Command menu. ⌘K / Ctrl+K toggles it, including from text fields; the visible button shows ⌘ K and remains available if the browser intercepts the shortcut. `/` is also available outside inputs, editors, other textboxes and dialogs. Escape returns one step in nested commands and closes at the root. The Command foundation supplies arrow-key navigation and Enter selection. The management sidebar uses this menu too. Rows use Hugeicons and a single aligned trailing action indicator, without reserving invisible checkbox space.

Pages and creation commands reuse the current portal's navigation manifest and role visibility. Creation commands open existing forms without creating a record. Staff assessments have one page, Assessments (`/app/assessments`, also matched by "assignments", "quizzes" and "exams"), and three creation commands: Create assignment, Create quiz and Create exam. Record results still open `/app/assignments/<id>`, `/app/quizzes/<id>` and `/app/exams/<id>`. Student menus have no staff actions. With no academy context, the menu offers navigation and academy links only.

Start session is a nested, keyboard-accessible workflow owned by the sessions module. Schedules are immediately selectable: type a title, audience or location and press Enter on the best match. Local search ranks exact names before prefixes/substrings and tolerates one mistyped letter in words of at least four letters; grade numbers never receive typo matching. Optional Grade, Track and Group chips open searchable shadcn Popovers, reachable with Tab and Enter, and return focus to the main search after selection/cancellation. Filter key events cannot select a schedule behind the popover. Live sessions appear first, followed by today's schedules on the Cairo calendar and other schedules. During search, match relevance determines the order. Every active startable schedule remains available regardless of planned time.

Escape/Back from review preserves the typed query and audience filters. Empty-input Backspace also returns one step. Filters select existing schedules and never narrow/change their actual audience. Grade changes clear track/group filters, and group schedules resolve their placement from their group. The final review shows the actual audience, year, attendance, location and planned times. Selecting/filtering does not start anything; explicit confirmation calls the existing authorized/idempotent session start. Already-live schedules open their existing session. Pending confirmation blocks dismissal and duplicate starts; errors retain the review for retry. Route, account, role or academy changes reset the menu.

Staff record search uses the current academy's open academic year: active student records, non-archived content units, assignments, quizzes and exams. Student record search uses only existing eligible published-unit and assignment discovery services in the current academy. Student exams remain available as navigation, not an exhaustive record search. Session, staff-directory, archived and cross-academy record search are outside this first slice.

Each domain returns at most six metadata results. Search contains no question keys, marks, private files, tokens or coupon secrets. Student results show name/placement and link by annual-record identity into the existing authorized record sheet; contact values are not included. Assignment results distinguish attached-unit context from standalone copies. Content and assessment results retain their existing authoritative access rules.

Queries debounce for 250 ms after two characters and are scoped by user, portal, academy and query, without persistent result caching. In-flight results from a previous account/query are hidden. Failed sources report partial availability and Retry without hiding successful groups or local navigation. Queries use the caller's Supabase session and existing domain services/RLS; no privileged search index or database migration is introduced.

Command was added through the shadcn CLI using the official generated component with Hugeicons. Input, Textarea, InputGroup and the owner-controlled theme/configuration were preserved.

## Staff sidebar and breadcrumbs

The staff sidebar shows Assessments as one link, active on the list and on every assignment, quiz and exam page (`ASSESSMENT_PATHS`). Quick Create lists Assignment, Quiz and Exam. Assessment workspaces and forms publish an Assessments breadcrumb parent that returns to the remembered list state (see the [assessments module](../assessments/README.md)); the staff header uses a page-published parent before the manifest parent. Switching academies from any assessment page opens the target academy's Assessments list without filters.
